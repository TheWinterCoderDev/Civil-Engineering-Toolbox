
# Security Policy

## Supported Versions

Civil Engineering Toolbox is an independently
maintained educational open-source project.

Security maintenance is provided on a
best-effort basis.

| Version | Supported |
|---|---|
| Latest published release | Yes |
| Legacy implementations | No |

## Reporting Vulnerabilities

Please use GitHub Private Vulnerability Reporting
to disclose security vulnerabilities.

Do not publish sensitive security information
through public GitHub Issues.

If private vulnerability reporting is unavailable,
please avoid publicly sharing exploit details.

## Numerical Correctness

Numerical errors, incorrect engineering assumptions
and reproducibility problems should normally be
reported through GitHub Issues.

Security-sensitive issues should be disclosed privately.

## Engineering Disclaimer

This toolbox is intended for educational and
research purposes.

It is not certified for industrial, construction,
structural or safety-critical engineering use.

Results must be independently validated before
application to real engineering projects.

## Maintenance

Reports are reviewed on a best-effort basis.

No guaranteed response time or remediation
schedule is provided.
