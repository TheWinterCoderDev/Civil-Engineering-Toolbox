
# Changelog

All notable changes to Civil Engineering Toolbox
will be documented in this file.

This project follows Semantic Versioning principles.

## [0.1.0] - 2026-11-24

### Added

- Initial modular Python package architecture.
- Geotechnical Engineering module.
- Terzaghi one-dimensional consolidation solver.
- Fourier-series approximation of normalized
  excess porewater pressure.
- Input validation and numerical error handling.
- NumPy-based vectorized calculations.
- Reproducible consolidation isochrone generator.
- Eight automated unit tests using pytest.
- Continuous integration with GitHub Actions.
- Scientific documentation for the consolidation model.
- Development dependency configuration.

### Changed

- Updated project identity to Civil Engineering Toolbox.
- Redesigned README around a multidisciplinary vision.
- Separated numerical calculations from visualization.
- Improved code organization and maintainability.
- Introduced consistent naming conventions.

### Preserved

- Original academic consolidation implementation.
- Original project history and engineering objectives.

### Known Limitations

- Only the geotechnical consolidation module is available.
- Fourier-series convergence depends on the number
  of retained terms.
- No comprehensive numerical error assessment.
- No advanced constitutive soil models.
- Not certified for safety-critical engineering use.
